1. Festival Theme
Theme: Creativity, Innovation and Fun!

The school will organise a one-day festival called The Ultimate School Festival. It will bring students, teachers, parents and visitors together to enjoy educational, creative, sporting and entertaining activities.

The festival website will allow visitors to explore activities, filter sessions according to their interests and save their favourite activities for easy reference.
2. Three Visitors' Needs
1. Students: Need to view the available activities, filter them by category and save their favourite sessions so they do not miss them.
2. Teachers: Need to see the festival timetable, know when activities take place and identify activities suitable for different age groups.
3. Parents and other visitors: Need clear information about the event, activity locations, starting times and special performances so they can plan their visit.
3. Ten-Session Festival Plan
Session	Activity	Description
1	Opening Ceremony	Welcome speeches and introduction to the festival.
2	Science Exhibition	Students showcase scientific projects and experiments.
3	Coding and Robotics	Demonstrations of computer programming and robots.
4	Music Performances	Choir, piano and instrumental performances.
5	Art and Creativity	Drawing, painting and craft exhibitions.
6	Sports Competitions	Football, basketball and athletics.
7	Mathematics Challenge	Fun mathematical puzzles and competitions.
8	Cultural Showcase	Traditional dances, clothing and cultural presentations.
9	Talent Show	Students showcase their special talents.
10	Closing Ceremony	Awards, appreciation and closing remarks.
4. Files Connecting HTML, CSS and JavaScript
The website will use three main files:
File	Purpose
index.html	Creates the website structure, including activity listings, buttons, search bar and navigation.
style.css	Controls the website's appearance, including colours, fonts, layouts and backgrounds.
script.js	Adds interactivity, allowing visitors to filter activities, save favourites and search for sessions.

How the files connect:
- HTML links to CSS using a <link> element inside the <head> section.
- HTML connects to JavaScript using a <script> element, preferably with defer.
- JavaScript interacts with HTML elements to make the website respond to visitors' actions.
5. Expected Outcome
The completed website will provide an interactive festival-planning experience rather than just displaying information like a poster. Visitors will be able to:
- Browse all ten sessions.
- Filter activities by category.
- Search for specific activities.
- Add activities to their favourites.
- View their saved favourite sessions.
Conclusion: The project will demonstrate how HTML, CSS and JavaScript work together to create an attractive, useful and interactive school festival website.
